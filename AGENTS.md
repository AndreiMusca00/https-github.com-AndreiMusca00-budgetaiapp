# Repository workflow

- The user reviews each successful app change and personally creates the commit and push.
- Leave changes uncommitted unless the user explicitly requests a commit for the current task.
- Push only when the user explicitly requests a push. A request to commit does not authorize a push.
- Before handing changes back, run checks appropriate to the change and briefly report what changed and what was verified.
- Preserve existing user edits. Keep local Xcode user settings and build outputs out of version control; keep shared schemes tracked.
